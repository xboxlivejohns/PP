# Service Finder Prototype V1

An isolated, vanilla HTML/CSS/JavaScript prototype for testing the Polished & Pristine Mobile service-finding experience. It does not modify or integrate with the live website.

## Open it

Open `index.html` directly in a browser, or serve this directory with any static local server.

## Structure

- `finder.js` contains the structured service data, deterministic recommendation logic, Finder state, and UI rendering.
- `finder.css` contains the isolated visual design and the replaceable `view-enter` animation.
- `index.html` contains the semantic application shell.

Use **Start again** to clear state. Test every route from the first question, then use **Back** or **Change my answers** to verify recalculation. Quote, service-page, and browse buttons intentionally show prototype placeholders.
